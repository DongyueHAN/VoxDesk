# 一句话演示记录

> 命令：`python scripts/demo_one.py`（模拟输入文本，不经过麦克风）
> 目的：录屏 / 截图用，一行一步，带耗时。

```text
────────────────────────────────────────────────────────────
[输入] 我说上句，你只接下句：左手看自家下路被双杀激动到大喊nice！
────────────────────────────────────────────────────────────
[回答] 右手发现是自己家打野
────────────────────────────────────────────────────────────
首 token      752 ms
LLM 总计      867 ms
播报时长     2414 ms（含播放）
端到端       3281 ms
────────────────────────────────────────────────────────────
```

## 说明

- 输入是**文本**（模拟用户说的话），跳过了 ASR；要演示语音识别请用 `--file xxx.wav` 或 `--seconds 4`。
- 回答是模型**现生成**的，每次可能不同——录屏以当次为准，本文件是一次真实运行的快照。
- `首 token` = 第一个字到达的时间；`播报时长` 含播放时间（不是合成耗时，合成约 0.15s）。
- 换个话题只需换 `--text`，system prompt 默认是"只接下半句"（`--system` 可覆盖）。
