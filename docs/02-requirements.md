## 1. 功能需求

### 1.1 端侧语音（本版重点）

| ID | 需求 | 优先级 | 验收标准 | 状态 |
| --- | --- | --- | --- | --- |
| REQ-F-001 | 系统支持全局热键按住说话（PTT），松开结束采集；按下时若正在播报则立即静音 | P0 | 任意前台应用下按热键均能录音；播报中按下，300ms 内静音 | 草案 |
| REQ-F-002 | 系统在**本机**将中文语音流式转写为文本，不依赖网络 | P0 | 断网状态可用；首字返回 ≤ 500ms；10 秒语句 CER ≤ 12% | 草案 |
| REQ-F-003 | 系统用**本地 TTS** 播报回复，支持按键打断并回到聆听 | P0 | 首包 ≤ 300ms；按下热键后播报立即停止 | 草案 |
| REQ-F-004 | 系统支持 VAD 自动断句，静音阈值可配置 | P0 | 静音 600ms 自动结束（可调 300–1200ms）；不切断句中小停 | 草案 |
| REQ-F-005 | 系统支持唤醒词常驻监听（端侧 KWS） | P1 | 唤醒率 ≥ 95%；误唤醒 ≤ 1 次/小时 | 草案 |
| REQ-F-006 | 系统支持实时降噪，且可 bypass | P1 | 风扇噪声下 ASR 字错率相对下降 ≥ 20%；bypass 后音质无可闻损伤 | 草案 |
| REQ-F-007 | 系统启动时自检音频设备，运行中可热切换 | P1 | 设备被占用/拔出时给出明确提示，不静默失败 | 草案 |
| REQ-F-008 | 系统支持回声消除（全双工前置） | P3 | — | 草案 |
| REQ-F-009 | 系统在**完全断网**状态下可完成听、想、说全链路 | P0 | 拔网线后仍能完成一次完整问答 | 草案 |

### 1.2 对话与理解

| ID | 需求 | 优先级 | 验收标准 | 状态 |
| --- | --- | --- | --- | --- |
| REQ-F-010 | 系统维护多轮会话上下文（最近 N 轮 + 摘要） | P0 | 指代消解可用："它"能指向上文对象 | 草案 |
| REQ-F-011 | 系统能将输入分流为：闲聊 / 工具调用 / 任务编排 / 委托 / 澄清 | P0 | 五类输入各 20 条抽样，分流准确率 ≥ 90% | 草案 |

## 2. 非功能需求

| ID | 需求 | 优先级 | 验收标准 | 状态 |
| --- | --- | --- | --- | --- |
| REQ-N-001 | 端到端首音时延：P50 ≤ 3.0s（纯 CPU 4B）/ ≤ 2.0s（GPU） | P0 | 连续 20 次测量取分位数 | 草案 |
| REQ-N-002 | 单机运行，8GB 内存为最低档、16GB 为推荐档 | P0 | 8GB 机器以 4B 模型可常驻 | 草案 |
| REQ-N-003 | 核心链路崩溃可恢复，任务不丢 | P0 | 强杀进程重启后任务与历史仍在 | 草案 |
| REQ-N-004 | 结构化日志 + trace_id 贯穿一次会话 | P1 | 一次会话所有事件可串起来 | 草案 |
| REQ-N-005 | 无明文密钥（云增强可选时亦同） | P1 | 仓库中无明文 Key | 草案 |
| REQ-N-006 | 运行时常驻内存 ≤ 5GB（含全部模型） | P1 | 任务管理器中观察 | 草案 |
| REQ-N-007 | 离线可用性：无网络时核心链路可用率 100% | P0 | 断网演练通过 | 草案 |
| REQ-N-008 | 冷启动（含模型加载）≤ 30s | P2 | 开机后首次可用时间 | 草案 |

## 3. 约束

| ID | 约束 | 说明 |
| --- | --- | --- |
| REQ-C-001 | 当前阶段只交付架构与图，不写实现代码 | 原型 = 图 |
| REQ-C-002 | ~~语音与模型能力依赖云 API~~ | **已废弃（v0.2.0）**，由 REQ-C-006 取代 |
| REQ-C-003 | 音频全程不出本机 | 本地 ASR/TTS 后成为硬保证 |
| REQ-C-004 | 只使用许可清晰的模型与组件（Apache/MIT 优先） | 逐一登记许可 |
| REQ-C-005 | 开发环境 Windows 11，脚本用 PowerShell | 与现有工具链一致 |
| REQ-C-006 | **本地优先**：默认全本地推理，云端仅作可选增强 | 断网可用是核心卖点 |
| REQ-C-007 | **半双工优先**：同一时刻只有一条音频通道活跃；全双工为 P3 可选项 | 见 ADR-0006 |
