## 1. M2 的目标（一句话）

> `07-roadmap.md` 的验收：**拔掉网线，说"你好，介绍一下你自己"，3.5 秒内听到回答。**

拆开就是四件事：**听懂**（ASR）→ **想清楚**（LLM）→ **说出来**（TTS，M1 已备）→ **接起来**（管线 + 时延埋点）。
另加一件 M1 挪过来的：**唤醒**（KWS）。

## 3. 时延预算：先定"谁该慢"，再谈优化

| 环节 | 预算 | 依据 |
| --- | --- | --- |
| VAD 静音尾 | 600ms | M1 实测（`min_silence` 可调，300–600 都 0 切错） |
| ASR 首字 | 300–400ms | `sherpa-onnx` + Paraformer 流式，CPU；**S4 实测 39ms**，预算大幅富余 |
| LLM 首 token | 900ms | `05` §6.2 目标 ≤1.2s，取中位 |
| TTS 首包 | 60–170ms | M1 实测（Piper RTF 0.026，首音 56–169ms） |
| **合计** | **≈ 2.0–2.3s** | 验收线 3.5s，留 1.2s 余量给工具与抖动 |

**如果超了，先看 VAD 的 600ms**——它是最大的一块，而且最容易调（代价是误切）。

## 4. 显存与内存：M2 开始才有这个问题

M1 的音频链路几乎不吃显存（VAD 2.3MB、Piper 60MB 走 CPU）。M2 一上 LLM，账就变了：

| 项 | 内存 | 显存（若 offload） |
| --- | --- | --- |
| Qwen3-4B（Q4_K_M） | 2.5 GB | 2.5 GB |
| KV cache（8k ctx） | 0.35 GB | 0.35 GB |
| 运行时/CUDA context | 0.30 GB | 0.3–0.6 GB |
| ASR（Paraformer 流式） | 0.90 GB | 0.9 GB |
| Piper + VAD + Python | 0.62 GB | ~0 |
| **合计** | **≈ 4.7 GB** | **≈ 4.5 GB** |

本机 16 GB 内存 + RTX 4060 8 GB 显存，**单独跑 M2 绰绰有余**；但到 M6 加 CosyVoice 时，8 GB 显存会同时被 LLM 与 TTS 抢（见 [`archive/09-tts-module.md`](archive/09-tts-module.md) §11.5）。

> **M2 阶段先别把 LLM 塞进显存**：4B 在 CPU 上首 token 约 0.9s，已经够用；把显存留给 M6。

## 5. M2 的特有风险

| 风险 | 早期症状 | 缓解 |
| --- | --- | --- |
| **Ollama 冷启动 11s** | 第一句话等十几秒 | `keep_alive=-1` 常驻；开机自启 |
| sherpa-onnx 模型下载大（~1GB） | 首次跑卡在下载 | 提前拉好，记录来源 URL 与版本 |
| ASR 与 LLM 抢 CPU | 首音忽快忽慢 | 分开测，先测单点延迟，再测串联 |
| 断网验收时模型重拉 | 拔网线后首次跑失败 | 验收前预拉模型；`OLLAMA_HOST` 只连本机 |
| 异步改造过猛 | 一套 `async` 写崩，连"能跑"都没了 | **同步优先**：S7 先用同步串联，跑通再优化 |

## 6. 闸门：M2 算不算做完了

六条全过才算（前两条来自 `07`，后四条是本轮补的可测项）：

| # | 判据 | 怎么测 |
| --- | --- | --- |
| 1 | 断网可用 | 拔网线跑完整一轮 |
| 2 | **首音 ≤ 3.5s**（P50，**保底线**） | 连说 10 次取中位 |
| 3 | ASR 首字 ≤ 500ms | 日志时间戳 |
| 4 | 工具调用合法率 ≥ 8/10 | 10 条指令回放（`05` §6.1 的测试集） |
| 5 | 四段时延埋点可见 | 一次会话的日志 |
| 6 | 连续 10 轮不崩 | 说 10 句不同的话 |

> **口径注**：3.5s 是**保底线**，`REQ-N-001` 的目标是 **3.0s**（对账见 `02` §1.10）。
> 两处不是"谁写错了"，而是"目标 vs 保底"；验收时先看 3.0s 是否达到、再看 3.5s 是否守住，**不许只报 3.5s 就说通过**。

## 7. 常见跑偏（M2 版）

| 跑偏 | 早期症状 | 纠正 |
| --- | --- | --- |
| **先优化再跑通** | 在写 asyncio 编排，闭环还没通 | S7 先同步串联，能跑再改 |
| **模型越换越大** | 4B 还没调好就看 8B | 4B 先达标，再谈升级 |
| **ASR 追 SOTA** | 在比 CER 榜单，管线还没通 | 只要"能读懂"就够，M2 不追指标 |
| **KWS 卡死进度** | 在录唤醒词数据 | PTT 顶着，KWS 允许滑出 |
| **不埋点** | 说"感觉慢"但说不清哪慢 | 四段耗时必须先有 |
