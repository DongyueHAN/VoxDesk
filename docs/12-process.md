## 0. 这份文档补的是"节奏"，不是"任务"

- `05-roadmap.md` 回答：**做哪些里程碑、各要几天**（M0–M7，32–40 天）
- `08-oss-shortlist.md` §4–§8 回答：**读哪些仓库、按什么顺序、什么时候停**（原 `10`，2026-11-05 并入）
- 本文回答：**这几件事怎么排在同一周里而不打架**

冲突时的优先级：**闸门（§2）> 里程碑（`05`）> 阅读顺序（`08` §4）**。
理由：闸门绑的是验收，验收不能改；阅读顺序只是建议。

## 1. 三条轴，三个节奏

| 轴 | 干什么 | 节奏 | 产出物 | 失败症状 |
| --- | --- | --- | --- | --- |
| **交付轴** | 写代码，让东西能跑 | **每天**，占主时段 | 可运行的模块 + commit | 一周过去还没有 `speak()` |
| **学习轴** | 读开源，判断"抄哪段" | **每天尾段 1 小时** | 一个**可执行动作** | 笔记越写越厚，代码 0 行 |
| **决策轴** | 记 ADR / 改选型 | **被触发时**，不排期 | ADR 或 CHANGELOG 一条 | 每步都写 ADR，写完没人看 |

三条轴唯一的硬关系：**学习轴服务于交付轴**。
读的那个仓库，必须是"这个冲刺要改的那段代码"的**上游**：

- 写 TTS → 只读 Piper 的**合成入口与 voices 文件**，不读它的训练脚本
- 写 VAD → 只读 silero 的 `get_speech_timestamps`，不读它的论文
- 写 ASR → 只读 `sherpa-onnx` 的 Python `examples/`，不读它的 C++ 内核

> 反过来说：**暂时不需要改的那部分，读它等于消费好奇心，不是投资工期。**

## 2. 闸门（Gate）

每个冲刺两道门：进门前确认前置，出门前确认验收。**门没过，不许开下一个冲刺。**

| 闸门 | 要回答的问题 | 通过条件 |
| --- | --- | --- |
| **G-进入** | 我要改的这段代码，上游是谁？ | 能说出"抄哪一段、抄完删掉什么" |
| **G-交付** | 这个冲刺的验收过没过？ | `09` §8 的清单逐条打勾（见 §6） |
| **G-决策** | 这个判断需要留档吗？ | 满足 §5 的三个触发条件之一才写 ADR |

## 4. 五条不变式

1. **一个冲刺只有一个主交付物**；学习只占每天尾段，不占主时段。
2. **每次学习必须换回一个可执行动作**（改配置 / 删代码 / 定选型）；换不回，下次不读。
3. **架构冻结到 M2 结束**：期间发现的"更优做法"记进 `08` §6 待验证区，**不进** `03`/`04`。
4. **任何"要不要换"的判断必须有实测数字**（首包 ms / 字错率 / 内存 GB）；没有数字，维持现状。
5. **每周日只做两件事**：更新 `05` 的进度列、写一条 CHANGELOG。**不写周报。**

## 5. ADR 什么时候才写

ADR **不是模块，也不是里程碑**，它是"二选一且难回头"时才产生的**副产物**。
三个触发条件，缺一不写：

| # | 触发 | 未来可能的例子 |
| --- | --- | --- |
| 1 | **推翻一份 `生效` 的 ADR** | M1 实测证明半双工不可用 → 推翻 `ADR-0006`（须新开一份，见 `00-spec` §11） |
| 2 | **引入新的外部边界** | M5 定下具体 harness（`codex` / DSH / Claude Code）→ 补 `ADR-0011` |
| 3 | **承诺变了且难回滚** | M2 实测 16 GB 装不下并行模型 → 改档位（连带改 `04` §9、`REQ-N-002`） |

**反例——这些都不该写 ADR**：

| 情形 | 该写在哪 |
| --- | --- |
| TTS 从 SAPI 换 Piper | `09` §1.1（换实现，接口没变） |
| 某个库升个版本 | `CHANGELOG.md` 一条 |
| "我觉得用 X 更好" | 哪都不写，等有实测数字 |

## 6. 完成判据：M0.5 算不算做完了

对照 `09` §8，五条全过才算：

| # | 判据 | 为什么是它 |
| --- | --- | --- |
| 1 | `speak("你好")` 200 ms 内出声 | 端到端通 |
| 2 | 长句按标点切分，句间无明显断裂 | 分句有效 |
| 3 | 同一句第二次播放命中缓存 | 缓存有效 |
| 4 | `stop()` < 200 ms **真停**（不是静音） | 打断可用 |
| 5 | 换成 Piper 后**调用方代码零改动** | **引擎可替换** |

第 5 条是整个 TTS 切片的意义：它证明"换引擎不改调用方"在你手里是真的，不是文档上的一句话。
