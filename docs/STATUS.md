## 2. 不能跑 / 只做了一半

| 项 | 现状 | 缺口 |
| --- | --- | --- |
| 流式 token / 边生成边播 | 整段返回，等待期间显示“思考中” | P2：SSE + 分句 TTS |
| 打断播报 | 只能“停止”当前播放 | 中止请求/多句队列未做 |
| 系统级热键 | 仅页面聚焦时；F2 按住、F3 切换 | 浏览器不能注册全局热键；需原生壳 |
| 桌面音频兼容性 | 代码已接 `getDisplayMedia` | 未在真机/多浏览器系统音频上验证 |
| ASR 准确率 | 外部 Paraformer 模型 | 自有语料未重新验收；按结果可能有错字 |
| 时间问题延迟 | 约 18s（2 轮工具） | P2：减少一次模型往返或换工具策略 |
| 1MB 上限后的体验 | 报错提示归档/新开 | 自动续聊/摘要未做 |
| Vtuber | 未实现 | 本轮明确不做 |
| 移动端 | 响应式 CSS | 未真机验证 |
| 依赖环境 | 先用外部 demo venv | 本地 `.venv` 未建；`requirements.txt` 已给 |

## 4. 存储规则（已实现）

| 限制 | 值 | 到达时 |
| --- | --- | --- |
| 活跃会话 | 30 | 新建 409，提示归档/删除 |
| 单会话 | 1MB（JSON 字节） | 追加 413，提示归档并新开 |
| 归档 | 100 | 新归档时自动删最旧归档 |
| 活跃删除 | 永不自动 | 仅用户操作 |

- `data/chats/<uuid>.json`、`data/archive/<uuid>.json`；原子写。
- 浏览器只存模式/朗读/联网/最近会话。
- 不存音频；朗读按文本重新合成。

## 6. 与原框架的差距

原框架 12 组件里，本仓库覆盖 `CMP-01` 的一部分（ASR，无 VAD/唤醒）、
`CMP-07` 的 Piper 合成（无队列/打断），以及展示层。`CMP-02/03/04/05/06/08/09/10/11/12`
均未实现。w0.5 额外做了浏览器端多轮存储、联网工具和陪伴模式，这些不在原 12 组件里，
但 PCM 约定、ASR 尾静音、TTS 锁、工具循环结构可回填。
