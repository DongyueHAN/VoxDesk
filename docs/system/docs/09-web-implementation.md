## 5. 与原设计的关键偏离

1. **推理出网**：`ADR-0005`（本地优先）在 Web 线被绕过——回答依赖 DeepSeek；只有 ASR/TTS 在本地。
2. **形态变化**：桌面应用 → 浏览器应用；全局热键只能在页面聚焦时生效。
3. **范围扩张**：多了联网工具、陪伴模式、声纹可视化、会话存储——这些在 02 需求池里**没有对应条目**。
4. **范围收缩**：VAD 自动断句、KWS、打断、工具执行、调度都没有。
